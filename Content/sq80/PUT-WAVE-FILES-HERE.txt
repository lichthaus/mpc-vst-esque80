ESQUE80 wave data folder
========================

This folder is empty on purpose. ESQUE80 does not ship any original wave data.
With nothing here, the plugin builds 75 stand-in waves when it starts and still plays.

If you have made your own dump of the original instrument, these files go here:

  wave0.bin  wave1.bin  wave2.bin  wave3.bin   raw 8-bit wave memory, 65,536 bytes each
  waves.txt                                    the wave table (text)
  bankD.pcb  bankC.pcb                         optional program banks (102-byte blocks)

The README describes each file format. Restart the MPC after adding them.
Please do not redistribute these files with the plugin.
